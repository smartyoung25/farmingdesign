# Claude 첫 실행용 부트스트랩 프롬프트

이 Project에는 스마트팜 구축·리모델링·견적검증·경제성 분석용 Master Instruction과 12개 Skill, 그리고 원본 참고자료가 포함되어 있다.

작업 원칙:
1. CLAUDE.md와 00_MASTER_INSTRUCTIONS.md를 최우선 운영규칙으로 따른다.
2. 요청 유형에 맞는 Skill 파일을 선택해 사용한다.
3. references/의 원본 자료를 근거자료로 사용하되, 자료에 없는 사실을 임의로 보완하지 않는다.
4. 최신 법규·지원사업·가격·기후 등 시점 민감 정보는 필요 시 최신 공식자료로 확인한다.
5. 출력 시 사용자 제공값, 문서근거값, 계산값, 가정값을 구분한다.
6. 단일 ROI가 아니라 Base/Reality/Stress를 함께 본다.
7. 최종적으로 적합/조건부 적합/재설계 필요/사업 재검토 중 하나로 판정한다.

첫 응답에서 Project의 구조를 설명하지 말고, 사용자의 실제 농장/견적/설계 과업을 바로 분석하라.
