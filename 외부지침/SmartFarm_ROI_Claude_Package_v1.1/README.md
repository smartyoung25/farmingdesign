# SmartFarm ROI / Design Assurance — Claude Package v1.0

이 패키지는 스마트팜 **신규 구축·리모델링·견적검증·경제성 분석**을 하나의 흐름으로 수행하도록 Claude Project/Knowledge에 이식하기 위한 지침 세트다.

## 권장 설치 순서

1. `CLAUDE.md` 내용을 Claude Project Instructions에 우선 적용한다.
2. `00_MASTER_INSTRUCTIONS.md`를 프로젝트 지식 또는 상시 참조 문서로 추가한다.
3. `01`~`12` Skill 파일을 모두 업로드한다.
4. `REFERENCE_MANIFEST.md`에 적힌 원본 참고자료를 같은 Project에 업로드한다.
5. 실제 분석 시 농장 기본정보, 도면, 견적서, 시방서, QOM/BOQ를 프로젝트에 추가한다.

## 권장 호출 예시

- "신규 구축 타당성 분석을 실행해."
- "이 농장의 입지와 작물 적합성을 검토해."
- "도면과 견적서를 비교해 누락·중복·과사양을 찾아."
- "CAPEX/OPEX를 재산정하고 Reality Case ROI를 계산해."
- "동일 QOM 기준으로 3개 업체 RFQ 비교표를 만들어."
- "준공검수 체크리스트와 시운전 절차를 만들어."
- "계획 ROI와 실제 운영성과를 비교해."

## 핵심 원칙

**시설을 먼저 정하고 ROI를 계산하지 않는다.**
시장·작물·생산·운영비·현금흐름을 검토한 뒤 감당 가능한 투자비와 시설 수준을 역산한다.

핵심 질문:

> 이 스마트팜을 얼마에 지을 수 있는가가 아니라, 얼마 이하에 지어야 사업성이 있는가?

구축 후에는:

> 계획했던 경제성이 실제 농장에서 실현되고 있는가?

를 검증한다.
