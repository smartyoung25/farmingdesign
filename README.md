# 스마트팜 구축 컨설팅 에이전트

입지·설계·운영·경제성 **4축**을 계산하고, 그 수가 **어디서 왔는지**를 함께 내는 엔진과
정적 산출물 생성기. 고객에게 가는 것은 HTML 산출물이고, 모든 수의 계산 출처는
`smartfarm_engine.py` **하나**다.

> 🔴 **이 문서는 「지금 이 리포에서 실제로 도는 것」만 적는다.** 2026-09-23 203차에
> 명령을 전부 실행해 확인했고, 가드가 여기 적힌 파일·명령이 실재하는지 매 회귀마다 잰다.
> 종전 `인수인계_스마트팜에이전트.md`는 **2026-07 경로**(Flask `app.py`)를 안내한다 —
> 그대로 따르면 **현행 시스템에 닿지 못한다**. 경위 보존용으로 남겨 두었다.

---

## 1. 5분 안에 돌려 보기

```bash
python build_site.py          # 산출물 20건 생성 — "생성 완료" 줄을 눈으로 확인
python audit_traceability.py  # 추적성 감사 — PASS 확인
```

🔴 **이 둘은 `pip install`이 필요 없다.** 외부 패키지 의존이 **0**이다(203차 실측 —
import 그래프를 따라가 확인). 파이썬만 있으면 고객 산출물이 나온다.

생성물은 리포 루트에 `SmartFarm_*.html`과 `index.html`로 떨어진다. **`index.html`부터
열면 된다** — 케이스별로 *통합보고서 → 컨설팅 패키지 → 판정 부록 → 4축 리포트* 순으로
묶여 있다.

## 2. 회귀 게이트 (바꾸기 전·후에 반드시)

```bash
pip install -r requirements.txt
python -m pytest test_engine.py test_registry.py test_cases.py -q
```

전체(파서·웹앱 포함)는 다섯 파일을 함께 돌린다.

```bash
python -m pytest test_engine.py test_registry.py test_cases.py test_chunking_v2.py test_webapp.py -q
```

- **기대 통과 수의 원본은 `작업지시서.md` 2절**이다(여기에 복제하지 않는다 — 두 곳에
  적으면 갈라진다).
- ⚠️ **skip 수를 확인할 것.** 파서 패키지가 없으면 관련 테스트가 **조용히 skip**된다.
  이 환경은 pip 패키지가 세션 간 유실된다.
- 🔴 **순서가 있다**: `build_site.py` → `pytest`. 산출물을 읽는 가드가 있어서
  낡은 HTML로 통과할 수 있다(151차에 실제로 그랬다).

## 3. 현행 실행 경로

| 하려는 것 | 명령 |
|---|---|
| 산출물 생성 | `python build_site.py` |
| 추적성 감사 | `python audit_traceability.py` |
| 참조 무결성 | `python verify_refs.py` |
| 웹 콘솔(입력 수집·미리보기) | `python -m uvicorn webapp:app --port 8600` |
| 단건 리포트(텍스트) | `python run_report.py` |

⚠️ **`app.py`는 현행 경로가 아니다.** 2026-07-17 이후 손대지 않은 Flask 구버전이고,
`flask`는 `requirements.txt`에 없다. 웹은 `webapp.py`(FastAPI)를 쓴다.

## 5. 이 시스템이 **하지 않는** 것

1절(불변 원칙)에서 옮긴다. 상품성이 여기에 있다.

- **작목·부지·업체를 고르지 않는다** — 후보와 근거를 나란히 낼 뿐이다.
- **시세를 조회하지 않는다** — 단가·노임·유가·금리는 **주입만** 받는다.
- **근거 없는 수를 만들지 않는다** — `[추정]`·`[확인요망]`로 표기하고 출처를 병기한다.
- **판정·추천을 자동화하지 않는다** — 단, **규칙 적용형 등급·판정은 예외**이고
  네 조건(레지스트리 등재 · 결정론 · 항목별 근거 행 · 임계값 주입 가능)을 모두 지킨다.
  그 산출물은 **본문이 아니라 「판정 부록」**에 따로 실린다.

## 6. 지금 비어 있는 것

- **원채원 원문**이 리포에 없다 — 회귀 기준(ROI 14.2% · Payback 7.1년)의 원문이 없다.
- **재무 가정 세 칸**(할인율 5% · 평가기간 10년 · 내용연수 15년)은 **주입되지 않은
  엔진 기본값**이다. 주입 자리와 입구는 열려 있고(케이스 JSON · 웹 폼), 산출물이
  *「주입되지 않았다」*고 표기한다.
- 그 밖의 미해결은 `작업지시서.md` §11과 `근거_확인요망대장_20260915.md`에 있다.
