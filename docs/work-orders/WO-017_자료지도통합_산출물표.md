# 작업지시서 WO-017: 자료 지도 통합 5→1 — 산출물 표 한 장 · 축을 열로

- 작성일: 2026-10-02
- 작업 유형: 리팩터링
- 선행 지시서: WO-011 · WO-015

## 1. 목적
- 산출물 27종을 분류하는 축이 여덟인데 **그중 다섯이 각자 화면을 받아** 같은 27행을 다섯 번 낸다. 축을 지우지 않고 **열로 내려** 한 화면에 모은다.
- 그 표의 산출물 이름을 **링크로** 만든다. 지금 `/axes`·`/for`는 27행을 보여 주고 **그중 어느 것도 열 수 없다**(죽은 끝).

## 2. 배경·사용자
- 사용자 지시(2026-10-02): *「기능을 구체적으로 매칭하여 사이트를 논리적으로 흐름에 맞게 정합적으로」* · ★사용자 결정 2026-10-02: 전면(21→9)
- 실측: 같은 27행을 내는 화면이 다섯이다(M6=5). 템플릿에서 산출물 제목 렌더가 **6개 파일**, 단계 렌더가 **6개 파일**이다.
- 네 화면의 **고유 정보는 열일곱 항목뿐이다** — `FUNCTION_GAPS` 다섯 건 · 지침 가·감점 대조 다섯 항목 · 기입 역방향 일곱 행. 나머지는 재배열이다.
- 실측: 흐름 화면의 렌즈가 축 대응표를 「입지·설계·운영·경제성」이라 소개하는데 그 화면 본문에 **경제성이 0회**다(M8의 한 건).
- 사용자: 산출물을 찾는 사람 전부 — 농업인·투자자·공공기관이 각자 다른 묶음을 보려 하므로 묶음은 **필터**여야 한다.

## 3. 범위
- 포함: 산출물 표 한 장(열·필터) · 꼬리 절 셋 · 산출물 행을 링크로 · 렌즈 라벨 모순 해소 · `/functions` `/axes` `/for` `/for/{name}` 흡수 · 가드 이동 · 뮤테이션
- 제외: **분류 상수 변경** — `PACKAGE_SPEC`·`FUNCTION_OF_CODE`·`PERSPECTIVES`·`STAGE_ORDER`를 한 글자도 바꾸지 않는다
- 제외: **새 축을 세우는 것**(273차 — 축을 세우는 것은 ★사용자)
- 제외: **참조 화면 구조**(별도) · **기입 통합**(WO-018) · **안내 화면 해체**(WO-019) · **날것 마크다운**(WO-020)
- 제외: **흐름 화면의 공종 × 단계 초안 확정** — 293차 초안이고 ★사용자 확정 전이다

## 4. 입력·출력
- 입력(전부 기존 구조): `PACKAGE_SPEC` · `STAGE_ORDER` · `PLATFORM_STAGES` · `FUNCTION_OF_CODE` · `PERSPECTIVES` · `FLOW_TARGETS` · `JUDGMENT_CODES` · `FUNCTION_GAPS` · 기입 역방향
- 출력: 산출물 표 — 열은 `산출물 / 단계 / 플랫폼 / 기능 / 대상 / 관점 / 엔진 함수 수 / 본문·부록`. 필터는 쿼리 파라미터로 받는다
- 지표: M6 `5 → 1` · M8 `2 → 1`(렌즈 라벨 한 건 해소. 나머지 한 건은 WO-020)

## 5. 기술 조건
- **기본 정렬은 명세 순서다** — 사람이 필터를 고르지 않으면 `PACKAGE_SPEC` 순서 그대로다(결정론: 같은 입력이면 같은 결과).
- **필터는 순위가 아니다.** 걸러진 건수를 보일 뿐 어느 묶음이 낫다고 하지 않는다.
- **없는 연결을 지어내지 않는다** — 열이 빌 수 있다. 빈 칸은 「대응 정의 없음」으로 적는다.
- **열 수 없는 행을 링크처럼 보이게 하지 않는다** — 그 산출물이 실제로 나오는 케이스가 없으면 링크를 걸지 않고 사유를 적는다.
- **라벨은 가리키는 화면의 본문에서 다시 읽어 맞춘다** — 라벨과 본문을 대조하는 가드를 함께 둔다. 렌즈 넷이 하나로 접히므로 라벨 문구 자체가 사라지는 쪽이 정석이다.
- 흡수되는 네 경로는 **쿼리를 담은 새 주소로 돌려보낸다**(307 또는 안내 줄) — 링크를 가진 사람이 막히지 않게 한다.

## 6. 작업 단위 (순서대로)
- T1: 산출물 표의 행·열을 만드는 조립 함수 — 완료 조건: 27행이 카탈로그와 한 건도 다르지 않고 여덟 열이 전부 기존 상수에서 나온다
- T2: 필터(쿼리 파라미터) — 완료 조건: 필터 없는 기본 순서가 명세 순서와 같고, 같은 쿼리면 같은 결과다
- T3: 산출물 이름을 링크로 · 열 수 없는 행은 사유 표기 — 완료 조건: 링크 가능한 행은 전부 200이고 나머지는 사유가 있다
- T4: 꼬리 절 셋(없는 것 다섯 · 가·감점 다섯 · 기입 역방향 일곱) — 완료 조건: 열일곱 항목이 하나도 빠지지 않는다
- T5: 네 경로 흡수 + 되돌림 안내 + 렌즈 라벨 정리 — 완료 조건: M6이 1이고 라벨↔본문 불일치가 0이다
- T6: 가드 이동 + 뮤테이션 + 차수 기록 + PRD 표 갱신 — 완료 조건: 7절 전부 통과
