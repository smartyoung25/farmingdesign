# 작업지시서 WO-022: 단계 순서 재정렬 — 타당성검증을 맨 앞으로(번호 유지)

- 작성일: 2026-10-02
- 작업 유형: 리팩터링
- 선행 지시서: 없음

## 1. 목적
- 단계 레일이 **①공종설계 → ②품질설계 → ③감리 → ⑤운영 → ⑥사후관리 → ④타당성검증** 순으로 서 있다. 사업 순서로는 타당성검증이 **맨 앞**이다.
- 이 변경은 **원문 순서를 복원한다** — 사업기획서 §5가 「투자실사 → 설계검증 → 성능보증」이라 적는데 223차가 그와 다른 순서를 화면에 썼다.

## 2. 배경·사용자
- ★사용자 결정 2026-10-02: **타당성검증을 맨 앞으로**(④①②③⑤⑥). **번호는 다시 붙이지 않는다**(제 추천, 채택).
- 실측: 단계 라벨이 든 곳은 **102곳**(조립 계층 66 · 콘솔 가드 19 · 엔진 가드 12 · 착수점 5). 동그라미 숫자는 1,536곳이지만 **대부분 일반 열거 기호**다(차수 기록·주석의 ①②③).
- 223차 주석이 적은 묶음은 그대로다 — 설계검증 = ①②③ · 성능보증 = ⑤⑥ · 투자실사 = ④. 레일과 탭이 **같은 순서**를 쓴다는 규칙도 그대로다.
- 사용자: 처음 흐름을 보는 사람. 투자 결정 전에 하는 일이 맨 뒤에 있으면 순서를 거꾸로 읽는다.

## 3. 범위
- 포함: `STAGE_ORDER` 원소 순서 · 플랫폼 탭 표시 순서(P3 → P1 → P2) · 화면의 「번호와 순서는 다른 것」 한 줄 · 순서를 단정하는 가드 갱신 · 뮤테이션
- 제외: **번호 재부여** — ①~⑥는 서비스 설계서가 붙인 식별자다. 바꾸면 원문과 어긋나고 일반 열거 기호와 섞여 잘못 바꿀 위험이 크다
- 제외: **정적 보고서의 순서** — 223차 ★결정으로 콘솔만 바꾼다. 같은 날 사용자 결정이다
- 제외: **단계 묶음(플랫폼) 변경** — 묶음은 그대로고 보이는 순서만 바꾼다
- 제외: **공종 × 단계 초안의 배정** — 순서와 무관하다(①10 · ②1 · ③1 · ④1 그대로)

## 4. 입력·출력
- 입력: `STAGE_ORDER` · `PLATFORM_STAGES` · 223차 주석의 묶음 규칙 · 사업기획서 §5의 순서
- 출력: ④①②③⑤⑥ 순서의 레일 · P3 → P1 → P2 순서의 탭 · 번호와 순서를 가르는 한 줄
- 지표: 걸지 않는다 — 순서는 수가 아니다. 가드가 순서 자체를 단정한다

## 5. 기술 조건
- **순서만 바꾼다** — 단계 이름의 글자를 한 자도 바꾸지 않는다. 라벨 102곳은 손대지 않는다.
- **묶음을 바꾸지 않는다** — 설계검증 = ①②③ · 성능보증 = ⑤⑥ · 투자실사 = ④.
- **왜 바뀌었는지 주석에 적는다** — 223차가 정한 순서를 되돌리는 것이므로, 그 차수의 결정을 지우지 않고 **원문과 다른 순서였다는 사실**을 함께 남긴다.
- 화면이 **「번호는 설계서의 이름이고 순서는 사업 순서다」**를 적는다. 적지 않으면 번호와 순서가 어긋나 보인다.
- 정적 보고서 생성기는 건드리지 않는다 — 순서가 둘로 갈린다는 것을 주석이 밝힌다.

## 6. 작업 단위 (순서대로)
- T1: `STAGE_ORDER` 원소 순서를 ④①②③⑤⑥으로 — 완료 조건: 레일 첫 칸이 ④타당성검증이고 단계 이름 글자 변경이 0이다
- T2: 플랫폼 탭 순서를 P3 → P1 → P2로 — 완료 조건: 레일과 탭의 단계 순서가 같다
- T3: 번호와 순서를 가르는 한 줄 + 223차 되돌림 사유 주석 — 완료 조건: 두 문장이 화면과 주석에 있다
- T4: 가드 갱신 + 뮤테이션 + 차수 기록 + PRD 갱신 — 완료 조건: 7절 전부 통과

## 8. 제약·주의사항
- 🔴 **번호를 다시 붙이지 않는다.** 동그라미 숫자 1,536곳 중 단계 라벨은 102곳뿐이고 나머지는 일반 열거 기호다. 일괄 치환은 범위 없는 정규식 치환 금지에 걸린다.
- 🔴 **223차 결정을 지우지 않는다.** 그 차수가 왜 그 순서를 골랐는지는 주석에 적혀 있지 않다 — **그 사실도 적는다**. 원문과 달랐다는 것이 이번 변경의 근거다.
- 🔴 **어느 단계가 더 중요하다고 하지 않는다.** 순서는 사업 순서이고 등급이 아니다.
- ⚠️ 정적 보고서와 콘솔의 순서가 **갈린다**. 223차 ★결정이 그렇게 정했고 이 차수는 그 결정을 따른다 — 갈린다는 사실을 주석과 차수 기록에 적는다.
- ⚠️ 순서를 단정하는 가드가 여럿이다(288·291차). 지우지 말고 새 순서로 갱신한다.
