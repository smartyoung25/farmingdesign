# 작업지시서(WO) — 이 리포 적용 방식과 색인

`dev-work-order-writer` 스킬(`.claude/skills/dev-work-order-writer/`, 246차 설치)의 양식으로 쓴
**개별 과제 지시서**를 모아 둔다. 리포 전체의 착수점인 `작업지시서.md`와는 **층이 다르다** —
그쪽은 「지금 어디까지 왔고 무엇이 규칙인가」, 이쪽은 「이 과제 1건을 추측 없이 실행하고 명령으로 판정하는 법」이다.

## 1. 스킬 규칙 ↔ 이 리포 대응표

| 스킬이 말하는 것 | 이 리포에서 | 근거 |
|---|---|---|
| 저장 위치 `docs/work-orders/` | 그대로 | 스킬 Workflow 7 |
| 파일명 `WO-NNN_[작업명].md`, 수정은 `WO-NNN-fix1_[작업명].md` | 그대로 · 번호는 이 색인의 마지막 번호 +1 | 스킬 Workflow 3·8 |
| WO 1건은 하루 이하 | **WO 1건 = 차수 1개 = 커밋 1개**. 한 차수에 안 끝나면 WO를 나눈다 | `CLAUDE.md` 작업 관례 |
| `docs/HANDOFF.md` 갱신 | **만들지 않는다.** `차수로그.md` 「갱신 이력」 맨 위 항목 + `작업지시서.md` 헤더 「최종 갱신」 한 줄 교체 + (테스트 수가 변하면) 2절 스냅샷 | 단일 착수점 원칙(`CLAUDE.md` 첫 줄) · 204차 분리 |
| 테스트 명령 | `CLAUDE.md` 「명령어」 절의 명령을 **그대로** 쓴다 — 지어내지 않는다 | 스킬 Common Mistakes |
| 수정 금지 파일 | `CLAUDE.md` 「손대지 말 것」 전체 + 과제별 추가분 | 스킬 5절 |
| 8절 제약 | `CLAUDE.md` 1절(절대 규칙)을 **항상** 포함 — 엔진 단일 계산 출처 · 근거 없는 값 금지 · 시세성 값 주입만 · 판정·추천 자동화 금지 · 회귀 벤치마크 | 1절 |
| 9절 보고 형식 | 스킬 9항 + `CLAUDE.md` 완료 보고 형식(확인한 것 / 확인하지 못한 것 / 사용자가 직접 봐야 할 지점) | `CLAUDE.md` 사실성 |
| (스킬에 없음) 개인 이름 | **쓰지 않는다** — 케이스 C1~C5 · 실측 표본 A* · 원문 출처 S* · 업체 V* 코드로 쓴다. 코드 ↔ 이름 매핑은 `case_display.py`에만 있다(파일 경로가 이름을 담으면 경로 대신 「C3 원문 폴더」처럼 적는다) | 사용자 지시 2026-09-28 「개인 이름은 무기명으로 처리」 · 183·184차 표시 계층 |
| 모르는 값 `[확인 필요: …]` · `[가정: …]` | 그대로. 리포의 `[추정]`·`[확인요망]` 표기와 **같은 뜻으로 섞지 않는다** — WO 표기는 지시서의 빈칸, 리포 표기는 산출물 수치의 근거 상태다 | 1절 「근거 없는 값 금지」 |

## 2. 이견 (스킬 원문과 이 리포 규칙이 갈리는 자리 — 섞지 않고 분리)

- **이견 1 — 「계획 먼저, 승인 후 구현」(Iron Law 6)**: 착수 프롬프트는 **스킬 원문 그대로 둔다**(다른 세션에 넘길 때 그대로 쓴다).
  다만 사용자가 「마무리까지 계속 진행하라」고 지시한 세션(2026-09-27, 메모리 `proceed-to-completion`)에서는
  **그 지시가 승인을 대신한다** — 계획은 WO 파일 자체와 착수 보고에 남긴다. 1절이 막는 행위(판정·추천 자동화, 근거 없는
  값 변경, 테스트 삭제·skip)는 어느 쪽이든 멈춘다.
- **이견 2 — 「Claude 앱이 쓰고 Claude Code가 구현」**: 스킬은 작성자와 구현자를 가른다. 이 리포에서는 **같은 세션이 둘 다** 하는 일이 많다.
  그래서 WO는 **구현 전에** 커밋 범위에 들어가고, 수용기준 체크(`[x]`)는 **명령을 실제로 실행한 뒤에만** 켠다.

## 3. 형식 검사

`python audit_work_orders.py` — 이 폴더의 모든 WO가 스킬 Verification Checklist의 **기계로 볼 수 있는 부분**을 지키는지 본다(WO-002). 251차부터 **R9 개인 이름 금지**도 본다.
사람이 봐야 하는 부분(수용기준이 목적을 실제로 덮는가, 가정이 타당한가)은 검사하지 않는다.
