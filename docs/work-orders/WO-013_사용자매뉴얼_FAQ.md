# 작업지시서 WO-013: 사용자 매뉴얼 · FAQ · Q&A (화면별)

- 작성일: 2026-09-29
- 작업 유형: 신규 기능
- 선행 지시서: WO-012

## 1. 목적
- 콘솔 화면별 설명이 **드롭다운 툴팁 한 줄**뿐이고 FAQ·Q&A가 없다. 메뉴별·화면별 설명을 한 곳에 묶어 처음 여는 사람이 혼자 따라갈 수 있게 한다.

## 2. 배경·사용자
- 사용자: 콘솔을 처음 여는 컨설턴트·검토자.
- 273차 점검(`근거_콘솔점검_20260929.md` 4절): **기입 워크플로 7단계는 매뉴얼이 아니라 JAS 준거 상태기계**다. 매뉴얼로 바꾸면 「어디까지 했는가」를 잃는다 — **새로 만들어 옆에 둔다**.

## 3. 범위
- 포함:
  - 매뉴얼 화면 — 메뉴별·화면별 설명(무엇을 하는 화면인가 · 무엇을 넣나 · 무엇이 나오나 · 안 나오면 왜)
  - FAQ 절 — 자주 막히는 자리(주입 대기 · 「미주입」의 뜻 · status 칩 읽는 법 · 케이스 코드 표기)
  - Q&A 절 — 답이 **리포 근거로 확인된 것만**. 확인 안 된 질문은 **「확인 필요」**로 남긴다
  - 각 설명에서 해당 화면으로 가는 링크
  - 가드 테스트 1건(라우트 목록과 매뉴얼 항목이 갈리지 않는지)
- 제외 (이번에 하지 않음):
  - `ENTRY_STEPS` 7단계를 매뉴얼로 **대체**하는 일(상태기계는 그대로 둔다)
  - 동영상·스크린샷 자동 생성
  - 외부 지식으로 FAQ 채우기(리포 근거 밖 답 금지)
  - 다국어

## 4. 입력·출력
- 입력: `webapp.py` 라우트 목록 · `ENTRY_STEPS`·`INJECTION_SLOTS`의 설명문 · 273차 점검 문서.
- 출력: 화면 1개(절 3개). 설명문은 **코드에 있는 문구를 옮기고**, 새로 쓰는 문장은 매뉴얼에만 둔다.
- 라우트가 늘면 매뉴얼에 **빠진 화면**이 드러나야 한다(가드가 대조).

## 5. 기술 조건
- 언어·라이브러리: Python 3 · FastAPI · Jinja2(리포 현행). 새 의존성 추가: 금지
- 파일 줄끝: `webapp.py`는 CRLF · 템플릿은 LF
- 수정 금지 파일·폴더: `CLAUDE.md` 「손대지 말 것」 전체 · 엔진 · 케이스 · 레지스트리 · `consulting_package.py`의 `ENTRY_STEPS`

## 6. 작업 단위 (순서대로)
- T1: 라우트 목록과 매뉴얼 항목 대조 함수 — 완료 조건: 빠진 화면 목록을 낸다
- T2: 화면 3절 + 메뉴 링크 — 완료 조건: 화면 응답 200
- T3: 가드 + 차수 기록 — 완료 조건: 7절 전부 통과
