# 작업지시서 WO-003: 콘솔 작업지시서 화면(읽기 전용)

- 작성일: 2026-09-28
- 작업 유형: 신규 기능
- 선행 지시서: WO-002

## 1. 목적
- 콘솔(`webapp.py`)에서 WO 색인과 각 WO의 수용기준 진행·형식 검사 결과를 본다. 지금은 파일을 직접 열어야만 알 수 있다.

## 2. 배경·사용자
- 사용자: 콘솔로 케이스를 운영하는 컨설턴트. 어떤 과제가 대기·완료인지, 어느 수용기준이 아직 확인되지 않았는지를 한 화면에서 본다.
- 245차 상단 메뉴의 「참조」 펼침 메뉴에 들어간다.

## 3. 범위
- 포함:
  - `GET /workorders` — 색인 표(번호 · 작업명 · 차수 · 선행 · 상태 · 수용기준 확인 수/전체 · 형식 검사 결과)
  - `GET /workorders/{WO번호}` — 한 WO의 9절 본문을 절별로 표시(수용기준은 체크 상태 그대로)
  - 상단 메뉴 「참조」와 푸터에 링크 1개씩
  - 웹앱 가드 테스트 1건
- 제외 (이번에 하지 않음):
  - 화면에서 WO 작성·수정·체크 변경(쓰기 없음 — 파일이 원본이다)
  - 마크다운 전체 렌더러 도입(새 의존성 금지 — 절 단위 텍스트 표시)
  - 수용기준 명령을 화면에서 실행하는 기능
  - 홈 화면 구성 변경

## 4. 입력·출력
- 입력: `audit_work_orders.audit("docs/work-orders")`와 `parse_wo()` 결과(WO-002). 없는 번호 요청 시 404.
- 출력: HTML 2화면. 수치(확인 수/전체)는 검사기 반환값의 표시만 하고 템플릿에서 계산하지 않는다.
- 번호 형식: `WO-001`, `WO-001-fix1` — 그 밖의 경로 값은 404.
