# 작업지시서 WO-023: 공종 설명 보강 — 재활용을 양액·관수에, 시공은 단계에

- 작성일: 2026-10-02
- 작업 유형: 데이터 처리
- 선행 지시서: WO-022

## 1. 목적
- 289차가 요청 열 낱말을 기존 열셋 공종에 이었고 **둘을 잇지 못했다** — 「시공」과 「재활용」이다.
- 둘을 서로 다르게 다룬다. **재활용은 설명에 넣고**, **시공은 공종이 아니라 단계에서 다룬다**고 화면이 적는다.

## 2. 배경·사용자
- ★사용자 결정 2026-10-02: 「양액재활용」의 재활용은 **4. 양액·관수 설비 설명에 넣는다**. 「시공」은 **공종에 넣지 않는다**(제 추천, 채택).
- 실측(289차 매핑 재확인): 이어진 여덟 — 부지(11·13) · 설계·감리(10) · 환경제어(5) · 양액(4) · 배관(3·4) · 전기(6) · 히트펌프(3). 못 이은 둘 — 시공 · 재활용.
- 시공을 넣지 않는 근거: 공종 열셋은 **금액을 분해하는 축**이고 시공은 **행위**다. 리포는 이미 시공을 단계 축에서 다룬다 — 플랫폼 P1 설명이 「설계문서 검토 → 시공 감리 → 준공 커미셔닝」이다.
- 사용자: 자기 사업의 낱말로 찾는 사람. 「양액재활용」을 찾으면 양액·관수 설비에 닿아야 하고, 「시공」을 찾으면 단계로 가야 한다.

## 3. 범위
- 포함: 4번 공종 설명에 재활용 추가 · 화면의 「시공은 공종이 아니다」 한 줄 · 매핑 재집계 가드 · 뮤테이션
- 제외: **공종 수 변경** — 열셋 그대로다. 새 공종을 만들지 않는다
- 제외: **금액·수량 변경** — 설명 문자열만 고친다. 어느 케이스의 금액도 다른 공종으로 옮기지 않는다
- 제외: **시공 공종 신설** — ★사용자 결정으로 넣지 않는다
- 제외: **다른 낱말의 재매핑** — 이어진 여덟은 그대로 둔다

## 4. 입력·출력
- 입력: `CAPEX_MAJOR_CATEGORIES`의 4번 설명 문자열 · `PLATFORM_STAGES`의 P1 설명 · 289차 요청 열 낱말
- 출력: 재활용이 이어진 매핑 · 「시공은 공종이 아니라 단계 ③감리에서 다룬다」 한 줄 · 못 이은 낱말 **둘 → 하나**
- 지표: 걸지 않는다 — 매핑은 수가 아니다. 가드가 낱말마다 이어졌는지를 다시 센다

## 5. 기술 조건
- 🔴 **설명 문자열만 고친다** — 공종 키·이름·금액·순서를 바꾸지 않는다. 엔진의 **수**는 한 자도 움직이지 않는다.
- **없는 설비를 있다고 적지 않는다** — 실측 케이스에 회수·살균 설비가 없으면 설명은 **범위**를 적을 뿐이고 그 사실을 함께 적는다(1절: 근거 없는 값 금지).
- **시공을 공종 설명에 넣지 않는다** — 낱말 검색은 통하지만 뜻이 틀린다. 온실 구조가 시공을 포함한다는 뜻이 되고 실측 금액은 그렇지 않다.
- **매핑을 손으로 적지 않는다** — 낱말이 어느 설명에 있는지는 **엔진 상수에서 다시 찾는다**(289차 방식 그대로).
- 추적성 감사가 착수 전과 같은 결과를 내야 한다 — 설명 변경이 `source_refs`를 건드리지 않는다.

## 6. 작업 단위 (순서대로)
- T1: 4번 공종 설명에 재활용 범위 추가 — 완료 조건: 매핑 재집계에서 재활용이 4번에 이어지고 공종 수가 열셋이다
- T2: 「시공은 공종이 아니라 단계에서 다룬다」 한 줄 — 완료 조건: 그 문장이 화면에 있고 플랫폼 P1 설명을 가리킨다
- T3: 가드 + 뮤테이션 + 차수 기록 + PRD 갱신 — 완료 조건: 7절 전부 통과

## 8. 제약·주의사항
- 🔴 **엔진 파일을 고치는 차수다.** 고치는 것은 **설명 문자열 하나**이고 수는 하나도 건드리지 않는다 — 그 사실을 가드가 재고 차수 기록이 적는다.
- 🔴 **설명을 넓혀 금액을 옮기지 않는다.** 재활용을 4번에 넣는 것은 **낱말이 닿게 하는 일**이고, 어느 케이스의 금액도 공종 사이를 이동하지 않는다.
- 🔴 **시공을 설명에 끼워 넣지 않는다.** 검색은 통하고 뜻은 틀린다.
- ⚠️ 실측 열다섯 표본 중 4번 공종에 금액이 있는 건수는 착수 전과 같아야 한다 — 설명이 바뀌어도 표본은 바뀌지 않는다.
- ⚠️ 엔진 주석에 ★를 쓰지 않는다(리포 관례 · 가드가 센다). 결정 표기는 레지스트리와 차수 기록에 둔다.
