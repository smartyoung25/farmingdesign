# 작업지시서 WO-021: 수에서 출처로 — 골조 단독부터

- 작성일: 2026-10-02
- 작업 유형: 신규 기능
- 선행 지시서: WO-012

## 1. 목적
- 인터뷰(2026-10-02)에서 **「이 수가 어떻게 나왔는가」를 말로 설명해야 했다**고 답했다. 그것도 한 수가 아니라 **네 수 전부**다 — 골조 단독 · ROI·회수기간·실질ROI · CAPEX 공종 분해 · 지침 요율·가점.
- 리포에는 근거 문서 **84건** · 참조 **179건** · 레지스트리 `source_refs` **191건**이 있는데, **화면에서 수 → 출처로 가는 경로가 없다**. 그 길을 만든다.
- 네 수를 한 차수에 다 덮지 않는다. **골조 단독부터** 하고 나머지는 같은 방식을 따라간다.

## 2. 배경·사용자
- ★사용자 결정 2026-10-02: 골조 단독은 **설명부터** 한다 — 엔진을 열지 않는다. 규격별 단가는 시세성이라 주입으로만 받을 수 있다.
- 실측(`python measure_console_ia.py`): 수를 내면서 출처로 가는 링크가 없는 화면 **6개**(M9) — 기능 지도 · 축 대응표 · 새 케이스 · 견적 허브 · 기본설계 · 관점별 입구.
- 실측(295차): 골조 단독 금액은 **주소에 무관하고 면적에 비례**한다. 면적 3,000㎡로 고정하면 네 지역이 전부 같고, 주소를 고정하면 3,000㎡ · 3,300㎡ · 6,800㎡에서 각각 달라진다.
- 사용자: 컨설턴트가 고객에게 화면을 보여 주는 자리. 수 옆에 출처가 없으면 **사람이 입으로 메운다**.

## 3. 범위
- 포함: 금액·비율 옆의 출처 표기 · 출처로 가는 링크 · 골조 단독의 「무엇에 비례하는가」 한 줄 · 가드 · 뮤테이션
- 제외: **규격별 단가 도입** — 시세성이라 조회하지 않는다(1절). 주입 설계는 별도 결정이 선행한다
- 제외: **ROI·회수기간·CAPEX 분해·지침 요율의 출처 표기** — 같은 방식을 따르되 화면과 계층이 달라 차수를 나눈다
- 제외: **근거 문서의 내용 수정** — 가리키기만 한다
- 제외: **새 근거 문서 작성** — 있는 것을 잇는다

## 4. 입력·출력
- 입력(전부 기존 구조): 레지스트리 `source_refs` · 참조 카탈로그 · 근거 문서 목록 · 엔진 함수가 쓰는 상수 이름
- 출력: 금액·비율 옆의 출처 칩과 링크 · 골조 단독 아래의 비례 관계 한 줄
- 지표: M9 `6 → 0`

## 5. 기술 조건
- **출처를 지어내지 않는다** — 레지스트리가 그 상수에 대해 적은 `source_refs`만 쓴다. 없으면 「출처 미등재」로 적는다(1절: 근거 없는 값 금지).
- **계산하지 않는다** — 수는 엔진이 낸 것을 그대로 쓰고, 이 차수가 만드는 것은 **그 수 옆의 글자와 링크**다.
- **비례 관계를 말로만 적는다** — 「평단가에 평을 곱한 값이라 주소와 무관하다」. 새 수를 만들지 않는다.
- **출처 링크는 실재를 확인한다** — 가리키는 문서가 리포에 없으면 링크를 걸지 않고 사유를 적는다.
- 측정기가 보는 것은 **출처 링크의 유무**다 — 금액 값 자체는 지표가 아니다.

## 6. 작업 단위 (순서대로)
- T1: 수 → 출처 대응을 레지스트리에서 끌어오는 조립 함수 — 완료 조건: 대응이 전부 `source_refs`에서 나오고 지어낸 것이 0건이다
- T2: 금액·비율 옆 출처 칩과 링크 — 완료 조건: 링크가 전부 200이고 미등재는 사유가 있다
- T3: 골조 단독의 비례 관계 한 줄 — 완료 조건: 주소 무관·면적 비례가 화면에 적혀 있다
- T4: 가드 + 뮤테이션 + 차수 기록 + PRD 표 갱신 — 완료 조건: 7절 전부 통과

## 8. 제약·주의사항
- 🔴 **출처를 지어내지 않는다.** 레지스트리가 적지 않은 출처를 화면이 말하면 그것이 **근거 없는 값**이다.
- 🔴 **규격별 단가를 만들지 않는다.** 금액이 지역·규격에 따라 달라야 한다는 요구는 ★사용자 결정으로 **설명부터**로 정해졌고, 단가는 시세성이라 주입으로만 받는다.
- 🔴 **수를 다시 계산하지 않는다.** 이 차수가 더하는 것은 글자와 링크뿐이다(1절 첫 줄).
- ⚠️ 네 수 중 하나만 덮는다 — 나머지 셋이 남는다는 것을 차수 기록과 PRD에 적는다. 적지 않으면 M9가 0이 되면서 **다 끝난 것으로 읽힌다**.
- ⚠️ 측정기의 표본(주소·품목·면적)은 고정값이다. 바꾸면 지표가 흔들리므로 바꿀 때 사유를 적는다.
