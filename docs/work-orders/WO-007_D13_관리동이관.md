- 작성일: 2026-09-28
- 작업 유형: 데이터 처리
- 선행 지시서: WO-005

## 1. 목적
- 결정 대기 D-13을 사용자 결정대로 반영하고 대장에서 닫는다. 143·146차가 원문에서 찾은 관리동·작업동 라인은 지금 골조·기초·커튼·피복 공종 안에 섞여 있어 `auxiliary_facility`(7. 부대시설)는 윤성호 1건(40,093,200)뿐이다.

## 2. 배경·사용자
- 사용자: CAPEX 카테고리 분해를 보는 컨설턴트.
- 150차 측정: 이관 대상 37,226,888(known_total 합의 0.470%) → 부대시설 40,093,200 → 77,320,088(1.93배), 전체 대비 0.506% → 0.976%. 맹주연 12,125,520·박규현은 **온실 전체 금액**이라 제외한 집계다.
- 현행 분류 규칙: **독립 공종만** 편입. 이관하려면 규칙이 「공종 안의 관리동·작업동 라인도 편입」으로 바뀐다.
- 결정: [확인 필요: D-13 — ⓐ 이관(분류 규칙 변경) / ⓑ 현행 유지]
- [가정: 오기수 「3. 관리동커텐공사」 2,817,269는 57차 보온커튼 관례대로 자동개폐에 둔다 — 37,226,888에 포함돼 있으면 T2에서 멈추고 보고한다]
- 선행 WO-005: 같은 표(`CAPEX_MAJOR_CASE_CHUNKS`)의 최선동 항목을 둘 다 건드린다 — 충돌을 피하려 순서를 둔다.
