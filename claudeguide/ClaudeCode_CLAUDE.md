## 절대 규칙
- 요청한 범위만 손댈 것. 인접 코드를 "개선"하지 말 것
- 테스트를 지우거나 skip으로 바꿔서 통과시키지 말 것
- .env 파일을 커밋하지 말 것
- main에 직접 push하지 말 것

## 작업 방식
- 3개 이상 파일을 건드리는 변경은 계획을 먼저 제시할 것
- 변경 후 테스트를 실행하고, 결과 출력을 그대로 보여줄 것
- 판단이 갈리면 조용히 하나를 고르지 말고 선택지를 제시할 것
- 축약어는 풀어서 설명할 것
- 반복 작업은 직접 하지 말고 스크립트로 만들어 재사용할 것
- 열어보지 않은 코드에 대해 추측하지 말 것. 파일을 먼저 읽을 것
